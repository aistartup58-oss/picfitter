# PicFitter

PicFitter is a free website with browser-based image tools. It is a website, not a mobile app.

Website: https://picfitter.online

## Tools

- Background remover: https://picfitter.online/free-background-remover/
- Compress image to an exact size (KB): https://picfitter.online/compress-image/
- Resize image to exact pixels: https://picfitter.online/resize-image/
- Convert images (HEIC, WebP, PNG, JPG) and make PDFs
- Passport photo makers for US, UK, Canada and Australia: https://picfitter.online/passport-photo/

## Privacy

All tools run in your browser. Your photos are not uploaded to a server.
